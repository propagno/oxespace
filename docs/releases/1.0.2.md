# OXESpace 1.0.2

A fix release for 1.0.1. Installs of 1.0.x on Windows update automatically; on Linux, install
the new package.

## Fixed

- **Long messages in Thread**: 1.0.1 raised the message limit to 1,000,000 characters only
  where the window hands the message over; the conversation service and the Claude and Codex
  connections still refused anything over 65,536 bytes, and the message failed with "Could not
  run thread agent". Every step now uses the same limit, for new messages, guidance sent to a
  running turn and edits of queued messages.

## Known limits

The limits listed in [1.0.0](1.0.0.md) still apply.
