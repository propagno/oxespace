# OXESpace 1.6.1

A polish and reliability update following 1.6.0, refining **Antigravity** sign-in and Gemini quota tracking, control
contrast, shell navigation, **Settings** organization, **OxeChat** ergonomics, and **OxeCode** chrome.

Installs of 1.6.0 on Windows update automatically; on Linux, install the new package (the AppImage updates itself).

## Antigravity in OxeChat & Usage

- **Paste authorization codes during CLI sign-in.** Native `agy acp --login` now handles ANSI terminal output cleanly
  when detecting verification prompts and adds a manual **Paste a code** toggle so you can paste verification or
  authorization codes directly into the login flow.
- **Accurate Antigravity Gemini quota measurement.** Usage tracking queries Gemini quota with project context
  (`loadCodeAssist` supplemented by `retrieveUserQuota`) and handles proto3 zero-fraction values properly so remaining
  quota is never misread or dropped.

## Interface & Navigation

- **High-contrast toggle switches.** OFF and ON switch states now meet high contrast targets across both light and dark
  themes (`>= 8:1` / `>= 12:1`), making inactive switches unmistakably readable at a glance.
- **Unified Usage control in the status bar.** All connected agents are consolidated into a single **Usage** trigger
  in the status bar, with human-readable stale reading ages and no expired `0m` countdowns.
- **Clearer window chrome and sidebar controls.** Added visual separation between the window menu bar (`File`..`Help`)
  and the surface switcher (**OxeCode / OxeChat / OxeQuery**), enlarged the sidebar footer icons (**Theme** and
  **Settings**), and fixed state filter counts so they stay unclipped at 110% display scale.
- **Secondary button framing.** Restored visible framing on standalone secondary action buttons such as *Check for
  updates*, *Reload*, *Verify*, and *Read now*.

## Settings & Integrations

- **Dedicated top-level Settings sections.** Split integrations into clear top-level sections for **MCP and Skills**
  (with separate **MCP** and **Skills** tabs and a direct *Manage MCP servers* button), **Phone and devices**, and
  **Git** (covering both **GitHub** `gh` CLI and **Azure DevOps** `az` CLI).
- **Cleaned-up Built-in tools.** Removed the leftover `CodeGraph` listing from *Built-in tools*.

## OxeChat & Delegated Work

- **Redesigned Delegate work dialog.** Rebuilt the *Delegate work* dialog with unified UI primitives, a balanced
  two-column layout, and a dedicated *Checkout preview* card.
- **Cleaner project sidebar and New Conversation controls.** *Removed projects* now starts collapsed in a disclosure
  section in the OxeChat sidebar, the *Add project* action stays visible beside *Projects*, and the New Conversation
  screen gives dropdowns, toggles, and status indicators clearer visual affordances.

## OxeCode Chrome

- **Fixed pane `⋯` menu layout.** Improved dropdown submenu spacing, right-aligned checkmarks, and expanded menu
  placement so *Close pane* is never clipped near window edges.
- **Less noise in workspace headers.** Removed the redundant elapsed timer from agent pane headers and the duplicated
  branch label from the OxeCode workspace topbar.

## Verify the Android APK

Before installing `oxespace-android-v1.6.1.apk`, check that it's the published file and that the project's key signed
it:

1. `sha256sum -c oxespace-android-v1.6.1.apk.sha256` (both files are in this release's assets).
   On Windows: `Get-FileHash oxespace-android-v1.6.1.apk` in PowerShell, and compare it with the value in the `.sha256`
   file.
2. `apksigner verify --print-certs oxespace-android-v1.6.1.apk` (Android SDK build-tools). The line
   `Signer #1 certificate SHA-256 digest:` must read `cc65d90afa2fde6518adad92d40769496a043b901f603eff0562e056cd4336e4`.

The signing certificate's SHA-256 fingerprint is:

`CC:65:D9:0A:FA:2F:DE:65:18:AD:AD:92:D4:07:69:49:6A:04:3B:90:1F:60:3E:FF:05:62:E0:56:CD:43:36:E4`

It's the same key as 1.5.x and 1.6.0, so the app updates in place. The full steps are in
[Verifying an APK before installing it](https://github.com/propagno/oxespace/blob/main/mobile/android/RELEASING.md#verifying-an-apk-before-installing-it).
