# OXESpace 1.5.2

A security fix for conversation access. We recommend updating.

Installs of 1.5 on Windows update automatically; on Linux, install the new package (the AppImage updates itself).

## Security

- **Conversation access.** This version strengthens the protection of a conversation's access setting. Your
  conversations, their history and your settings stay as they are.

## On the phone

- **Some slash commands typed on the phone no longer run.** Use the phone's Stop button or the desktop app.
