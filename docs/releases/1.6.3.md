# OXESpace 1.6.3

A major visual, workflow, and performance release: OXESpace adopts the pure **Obsidian Minimal** design language across
8 built-in color schemes and True Black OLED, upgrades **OxeChat** with editorial thinking previews, contextual code
block actions, an approval carousel with inline command editing, drag-and-drop and `@` context sources, inline plan
review comments, custom agents with declarative handoffs, and **MCP 2.0**, and delivers a deep end-to-end performance
overhaul across both **OxeCode** terminals and **OxeChat** agents.

Installs of 1.6.2 on Windows update automatically; on Linux, install the new package (the AppImage updates itself).

## Pure Minimal Aesthetic & Visual Craft

- **Official `kepano/obsidian-minimal` color system.** Added 8 built-in color schemes (**Minimal**, **Obsidian**,
  **Flexoki**, **Nord**, **Catppuccin**, **Dracula**, **Gruvbox**, and **Solarized**) with live Monaco and terminal
  synchronization, plus **True Black OLED / Pure White** surface mode and the monochrome Mandacaru Ramo mark.
- **Unified navigation and provider identity.** Standardized leading AI provider icons across OxeCode and OxeChat
  sidebars and pane headers, removed the legacy `1×1` toolbar button, and clamped edge tooltips cleanly inside the
  viewport at native zoom.

## OxeChat Workflow & Agent Experience

- **Editorial Thinking preview.** Agent reasoning now renders full Markdown with a live active bold heading subtitle, a
  bounded 160 px auto-scrolling preview while streaming, a full-row clickable summary header, and a persisted
  `Thinking style` preference (`Auto-scroll preview`, `Collapsed`, `Expanded`).
- **Contextual Code Block actions & semantic diffs.** Code blocks now expose **Run in Terminal**, **Wrap**,
  **Open in Editor** (with virtual scratch tabs), and **Copy**, alongside semantic added/removed diff highlighting.
- **Approval Carousel `1/N` & inline command editing.** Multiple pending approvals step smoothly in a `1/N` dock
  carousel with safe-only batch approval (`Allow N safe`) and inline command editing that monotonically re-evaluates
  command risk before execution.
- **Composer Drag-and-Drop, large paste chips & `@` context.** Drop files, folders, or images directly onto the
  composer; pastes above 10,000 characters turn into compact removable chips (configurable in Settings); attach
  `@changes`, `@terminal`, `@folder`, and `@thread` context from the `@` menu or `+ Context`.
- **Lean Conversation Preferences, Steer / Queue & Ask in Side Chat.** New calm defaults in **Settings › Agents** and
  **Settings › Notifications** (separate approval vs. completion notification modes), configurable `Enter` vs.
  `Alt+Enter` Steer/Queue behavior while a turn is running, and **Ask in Side Chat** to branch a quick question without
  interrupting the active turn.
- **Inline comments on `ExitPlanMode` plans.** Attach structured per-section comments while reviewing a plan and submit
  all feedback cleanly on **Request changes**.
- **Custom Agents, `Ask` mode & declarative handoffs.** Discover custom agents from `.oxe/agents/*.md`,
  `.github/agents/*.agent.md`, `.claude/agents/*.md`, and `~/.oxe/agents/*.md` with read-only security guardrails,
  switch into read-only **Ask** mode from the calm mode menu, and continue turns through declarative handoff buttons.
- **MCP 2.0 (Streamable HTTP/SSE, OAuth 2.1, Tool Picker & Resources).** Native remote Streamable HTTP and SSE MCP
  transports, OAuth 2.1 + PKCE with encrypted OS keychain token storage and auto-refresh, a composer **Tool Picker**
  preserving MCP Pinning & Quarantine protections, and attachable **MCP Resources** chips.
- **Antigravity parity & WebPreview polish.** Added full Antigravity cross-provider MCP/delegation support (SQLite
  Migration 114) with clearer zero-jargon tool guidance, restored the Antigravity Gemini 5-hour quota window via
  `retrieveUserQuota` fallback, and refined WebPreview CDP error diagnostics to preserve Chromium `errorText` and avoid
  noise from external-site subresources.

## OxeCode & OxeChat Performance Overhaul

- **Direct `MessagePort` (`ptyHost ↔ Renderer`) & Flow Control.** Live PTY output and flow-control ACKs (`100k`/`5k`
  watermarks) now stream directly between the `pty-host` utility process and the renderer with 5 ms origin batching,
  bypassing Electron Main on the hot path while preserving `PtyRingBuffer`, `sinceSeq` replay, parked panes, and
  `PaneScreen`.
- **Smoother terminal resize, search, links & ConPTY stability.** Added 100 ms asymmetric `cols` reflow debouncing
  (keeping vertical `rows` resizes immediate), lazy `SearchAddon` (`highlightLimit: 1000`), a 10 s TTL link resolution
  cache (fixing Markdown `**~/` path wrapping), Windows ConPTY kill/spawn throttling and exit flush guards, adaptive
  `smoothScrollDuration`, and `clearTextureAtlas()` on DPI/font/theme recovery.
- **O(1) incremental streaming Markdown & off-thread worker.** Streaming responses split closed top-level blocks into
  memoized worker-rendered chunks with a single shared `ResizeObserver` across `ThreadTimelineWindow`, an LRU Mermaid
  SVG cache, and a DOM-free compiled `threadRender.worker` verified at build time.
- **Leaner agent tool loops & prompt caching.** Added a semantic MCP output compactor (protecting JSON/YAML/TOML),
  in-memory `ToolResultCache` deduplication with mutation invalidation, incremental `oxespace_get_job_output` deltas,
  prompt cache stale/break hints in the Usage Ring, optional utility-model routing with graceful fallback, and batched
  multi-provider `oxespace_tools_search` (~1 ms p50 across 250+ tools) for Codex and Antigravity.

## Verify the Android APK

Before installing `oxespace-android-v1.6.3.apk`, check that it's the published file and that the project's key signed
it:

1. `sha256sum -c oxespace-android-v1.6.3.apk.sha256` (both files are in this release's assets).
   On Windows: `Get-FileHash oxespace-android-v1.6.3.apk` in PowerShell, and compare it with the value in the `.sha256`
   file.
2. `apksigner verify --print-certs oxespace-android-v1.6.3.apk` (Android SDK build-tools). The line
   `Signer #1 certificate SHA-256 digest:` must read `cc65d90afa2fde6518adad92d40769496a043b901f603eff0562e056cd4336e4`.

The signing certificate's SHA-256 fingerprint is:

`CC:65:D9:0A:FA:2F:DE:65:18:AD:AD:92:D4:07:69:49:6A:04:3B:90:1F:60:3E:FF:05:62:E0:56:CD:43:36:E4`

It's the same key as 1.5.x, 1.6.0, 1.6.1, and 1.6.2, so the app updates in place. The full steps are in
[Verifying an APK before installing it](https://github.com/propagno/oxespace/blob/main/mobile/android/RELEASING.md#verifying-an-apk-before-installing-it).
