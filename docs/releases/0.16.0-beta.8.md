# OXESpace 0.16.0-beta.8

This beta improves how Thread presents questions, provider approvals and background activity, and removes the redundant partial-history notice above the composer.

- Questions have more room for their options while keeping the answer controls visible.
- MCP tool approvals are identified as tool requests instead of shell commands. The card explains why Full access does not automatically answer a provider or MCP request.
- `ExitPlanMode` approvals show the plan as readable Markdown; the exact original request remains available for inspection.
- Provider background activity and local jobs are stacked in the side panel. Long agent results stay collapsed until opened.
- The “Recent messages are loaded” notice no longer appears. The **Load earlier messages** control remains available at the top of a conversation when older history exists.
- Web Preview tab retries now ignore stale guest events, and the Electron smoke checks wait for the active tab before asserting its state.

The Claude Code OAuth refresh error and provider tool errors shown in the reported screenshots are separate provider outcomes; this release does not change Claude Code authentication or its tool rules.

The release workflow verifies typecheck, lint, tests, Electron build and E2E on Windows and Linux before publishing the prerelease artifacts. No local Docker run is required.
