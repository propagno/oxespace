# OXESpace 0.14.2

This maintenance release closes the session recovery and delegation continuity gaps reported after 0.14.1.

## Thread session recovery

- `/resume` now reads the native Codex SQLite session catalog used by the CLI picker, including active sessions whose rollout file is temporarily locked.
- Older Codex installations fall back to bounded JSONL discovery, with support for large session metadata, complete history, `CODEX_HOME`, titles, models, and timestamps.
- Claude discovery now follows the provider's complete project-path encoding and respects `CLAUDE_CONFIG_DIR`.
- The resume dialog lists the complete native catalog and can filter by prompt, model, branch, date, or session ID.

## Delegation continuity

- An explicit delegation control call can reconnect a replacement requester session after restart or session replacement.
- Reconnection requires the exact original workspace, project identity, and checkout path.
- Delegated worktree agents and unrelated checkouts remain unable to assume requester control.
- Delegated work entries now open their persistent Thread, destination Code pane, or focused recovery details instead of becoming inert.

## Navigation and layout

- The Code sidebar keeps Accounts, Settings, and Collapse visible while long workspace lists scroll independently.
- Thread delegated-work navigation now routes terminal-backed and Thread-backed tasks consistently.

## Verification

- The native Codex catalog was checked against the real CLI picker and returned the same 18 sessions for the development checkout.
- Typecheck, lint, production build, bundle budgets, Thread/sidebar E2E, and the complete Electron test suite passed before release.
