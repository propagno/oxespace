# OXESpace 1.2.0

Thread conversations you can step back from, a smaller installer, and your agent's usage at a
glance. Installs of 1.1.x on Windows update automatically; on Linux, install the new package (the
AppImage updates itself).

## A smaller installer

- **About 210 MB smaller.** The Windows installer is about 195 MB (was 403 MB) and the `.deb` about
  182 MB (was 401 MB). The semantic search model no longer ships with the app.
- **Repository search for agents works without it.** `oxespace_semantic_search` and
  `oxespace_hybrid_explore` search exact repository terms (identifiers, strings, tests, config) and
  code structure, and each result names the sources that answered.
- **Search by meaning is optional.** Turn on *Settings › Agents › Semantic index (beta)* to
  download the model (about 270 MB) into the app's data folder, where it stays across updates. On
  networks without internet access, use *Import from folder* with a copy of the model. An index you
  already built is used again as soon as the model is back.
- How often agents call these tools is counted on this machine only (shown in the same setting),
  to decide the index's future. Nothing is sent.

## Conversations

- **Rewind can be undone.** Rewinding sets the later turns aside instead of deleting them: they stay
  readable and greyed, and **Redo** brings them back, files included. Your next message confirms
  the rewind.
- **Retrying a failed turn** that changed files asks first: undo its changes and retry, retry
  without undoing, or cancel. A turn whose file checkpoint is gone is not undone blindly.
- **The agent's reasoning** shows as a "Thought for Xs" block that collapses when done and is
  included in exports.
- **Turn time counts the agent's work**, not the time it waited for your answer: "Worked 1m 3s ·
  waited for you 40s".
- **Full access stays full access after a plan.** Approving a Claude plan no longer brings back an
  approval prompt for every command that follows.
- Scrolling a long conversation is smoother, and the prompt that stays at the top while you scroll
  no longer lets text show through.
- The live status no longer repeats the recent activity the conversation already shows.
- A failed conversation counts on the rail badge only until you open it.

## Usage at a glance

- **The bottom bar shows your agent's 5-hour and weekly usage** ("5h 42% · wk 18%"), with time to
  reset in the tooltip, in Code and now in Thread too. It refreshes every minute while the app is
  visible, and when you click it.

## Git

- **Commit** and **Create pull request** show as primary buttons, and the Git panel fills its space.

## Known limits

- Thread conversations with Claude need a recent Claude Code CLI; update it if a conversation fails
  to start.
- Claude usage comes from the same account endpoint the Claude Code CLI uses. If it is rate
  limited, OXESpace waits before asking again and shows the last reading as not current.
- The limits listed in [1.0.0](1.0.0.md) still apply.
