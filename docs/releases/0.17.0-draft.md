# OXESpace 0.17.0 (draft)

> Draft notes. The version number and date are set when the release is cut.

## Highlights

- **OxeQuery**, a third mode next to Code and Thread. See your containers
  (Docker or Podman) and query PostgreSQL and MongoDB without leaving OXESpace.
  - Containers: state, ports, logs, start / stop / restart, run a command, open a
    shell.
  - PostgreSQL: schema tree, SQL editor with query tabs and history, sortable
    results, row details, cancel.
  - MongoDB: databases, collections, `find`, `aggregate`, documents or table.
  - One click from a database container to a ready connection.
  - Read-only by default; destructive statements ask first; passwords live in the
    operating system's secure storage.
- **Thread**: per-message delivery state, a queue that pauses after a stop or a
  failure, context-window usage in the ring, and a verified *Rewind to here* for
  Codex and Claude.

## Also in this release

- Faster startup: the Editor and Review panes and the OxeQuery mode load on
  demand. The preload bridge is minified.
- Incremental Thread reads (a cursor with an epoch) instead of rereading the
  whole window on every change.

## Known limits

- OxeQuery has no SSH tunnels and does not edit rows or documents yet.
- TLS "required" does not verify the server certificate.
- Podman support has not been exercised on a machine with Podman installed.
- Rewinding to the first Claude message is not offered.
