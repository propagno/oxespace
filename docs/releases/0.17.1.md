# OXESpace 0.17.1

A patch release for 0.17.0. No database migration; the 0.17.0 schema is unchanged.

## Fixed

### OxeQuery
- **Testing a connection no longer saves a copy each time.** "Test connection" saved the
  connection (password and environment included) on every click; repeated tests created
  duplicates. It now updates the one record it created.
- **A long statement no longer restarts the whole database worker.** The worker's time
  budget was shorter than the statement timeout a connection may allow (up to an hour),
  which dropped every connection, SSH tunnel and export in flight. The budget now follows the
  connection's statement timeout.
- **Docker and Podman are found at their install locations on Windows** when they are not on
  `PATH` (the paths were corrupted by escape sequences).
- **The schema tree and autocomplete no longer fail while a query is running**; they wait
  for it. A failed load is retried, and DDL refreshes the suggestions.
- **A long MongoDB export or import is no longer closed by the idle timer.**
- **Export matches what you ran**, not the editor's current text. The row limit starts at the
  connection's own limit, and table browsing is ordered by primary key so pages do not skip
  or repeat rows.
- **Agents:** container log lines are masked (connection-string passwords, bearer tokens,
  `password=` and `token=` values, private keys). "Allow reads for this run" lapses after four
  hours.

### Thread
- **"Always allow this MCP tool" works.** The request was refused by the IPC layer.
- **Claude tool results delivered as typed blocks show their text** instead of an empty output.
- **A single Claude protocol line larger than 1 MiB no longer fails the turn** (limit raised
  to 32 MiB, as for Codex).
- **Codex `/fork` uses the thread's own sandbox and approval policy.**

### App
- **Changes lists files an agent created but did not stage** (they were invisible to review).
- **The first terminal no longer waits on a stalled RTK download** (3 s budget, 30 s idle
  timeout on the download itself).
- **Pre-release installs are offered the stable release** (`0.16.0-beta.8` → `0.16.0`) by the
  manual and `.deb` update check, which now compares full SemVer.
- **A crashed interface reloads itself** (up to three times a minute) instead of leaving a
  blank window.

## Known limits
Unchanged from 0.17.0; see `docs/releases/0.17.0.md`.
