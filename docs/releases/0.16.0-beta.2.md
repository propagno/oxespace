# OXESpace 0.16.0-beta.2

This prerelease continues the Code and Thread workbench redesign. It remains on the beta update channel; the stable 0.15.2 channel is unchanged.

- Code and Thread navigation are more compact and consistent. Branch identity stays with the active pane or conversation. Code workspace terminal groups can be expanded independently, including workspaces with the same name; their state survives restart. Reopening a known folder selects an existing workspace without changing its layout or relaunching agent commands.
- Thread presents live activity and request outcomes more clearly, including failures and pending interaction. Conversation changes and completed command activity are grouped for easier reading.
- Code adds direct Connections and Activity entry points, a resizable editor file tree, and a lighter local Git Control view. Activity distinguishes local jobs from delegated work. The Tools redesign is still in progress.
- Web Preview uses a native Electron browser surface with scoped automation. Agent access and external navigation require explicit consent; views and permissions are released when the panel closes or the app restarts.
- The beta includes further keyboard, accessibility and visual refinements to settings, dialogs, sidebars and conversation layout.

**Beta limits:** remote OAuth connectors, the unified cross-source Activity action model and the single Tools action registry are not complete. The Windows installer side effects still need validation in an isolated VM. Linux packaged visual and performance checks remain release gates.

Release validation is performed by the unified Windows and Linux CI workflow, including typecheck, lint, unit/integration coverage, build, Electron E2E, performance budgets, packaged smoke tests and artifact verification. See `docs/plans/connectivity-panels-tools-redesign.md` and `docs/audits/web-preview-windows-2026-10-01.md` for scope and validation limits.
