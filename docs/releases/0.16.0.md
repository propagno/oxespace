# OXESpace 0.16.0

The first stable release of the 0.16 line. It collects everything shipped in
`0.16.0-beta.1` … `0.16.0-beta.8` and adds a redesigned shell, a Changes (diff
review) panel, a connector catalog and pull-request status in Thread. Beta
installs update to this release automatically; stable installs move from 0.15.2.

## Highlights

- **Thread is a first-class mode.** Independent Thread projects, native Claude Code
  and Codex conversations, approvals, questions and background tasks that stay
  visible, checkpoints with **Undo**, and a project terminal.
- **Calmer transcript.** Three views — **Summary**, **Normal** (default) and
  **Verbose**, switched with `Ctrl+O`. Normal folds actions into one line such as
  *Ran 4 commands, edited 2 files*; the raw command is one click away.
- **A prompt box that does the work.** `@` mentions project files, `+` attaches
  images or opens connectors, access and approvals are one control, and a usage ring
  shows your plan allowance.
- **Changes panel.** Branch or uncommitted diff against a base, side by side, with
  a file tree, *Viewed* marks, large-diff mode and **line comments** that can be
  sent back to the agent.
- **Pull-request status.** The branch's PR, its checks and a ready-made
  *Fix failing checks* prompt, plus auto-merge through `gh`.
- **Connector catalog.** Forty ready-to-add MCP servers with brand tiles. One click
  adds, trusts and starts a connector; remote connectors open the browser sign-in
  for you and wait for you to finish. Enabled servers are attached to Thread
  conversations.
- **New shell.** Frameless window with inset panels, a File/Edit/View/Help menu
  bar, an icon rail with the project tree, and design tokens used across the
  interface (smaller, more consistent type and radii; larger hit targets).

## Also in this release

- Linux packages (AppImage and `.deb`) are built, tested and published by the same
  pipeline as Windows.
- Web Preview uses a native Electron surface with scoped, consent-based
  automation.
- Compact diagnostics: Settings → Diagnostics → Export report (bounded, redacted).
- The Electron runtime moved to a supported line (44) with a CI gate on its
  support window; production and build-tool dependency audits are blocking.
- File-system confinement compares canonical paths without case folding; a
  database upgrade stops, with data untouched, if a verified backup cannot be made.
- The **Agents** page was removed from navigation. Provider sign-in lives in Thread
  accounts.

## Upgrading

- The database migrates forward (schema 63) and a verified backup is kept before
  the upgrade; **downgrading to an older version is not supported**.
- Review comments saved on diff lines in earlier builds are kept and appear in the
  new Changes panel.
- The Windows installer is **not code-signed**; SmartScreen may warn. Compare
  `SHA256SUMS.txt` before running it.

## Known limitations

- Thread contracts are covered by fixtures, transport tests and a packaged smoke
  test; campaigns with authenticated providers across CLI versions and long
  sessions are still widening. Provider-side behaviour (rate limits, tool rules,
  authentication refresh) is outside OXESpace's control.
- Voice dictation is available on Windows only.
- The `.deb` does not self-update; install the new package.
- No macOS or ARM packages.
- Teams is a first, narrow version of agent coordination.

See the [platform specification](../PLATFORM_SPEC.md) for supported platforms and
requirements.
