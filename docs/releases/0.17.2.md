# OXESpace 0.17.2

A patch release for 0.17.1. No database migration.

## Fixed

- **AI agents can use OxeQuery.** Every `oxespace_db_*`, `oxespace_mongo_*` and
  `oxespace_container_*` tool answered "OxeQuery is unavailable" in every build, because the
  internal MCP server was never handed the OxeQuery gateway. When OxeQuery really fails to
  start, the agent and the OxeQuery view now get the reason.
- **Conversation cost no longer grows out of proportion.** Claude reports a running total for
  the process; adding it for every turn made a long conversation's cost grow quadratically
  (US$ 1 895 on one conversation). Each turn now counts only its own step. Amounts recorded
  before this release are not corrected.
- **A finished turn no longer shows a clock that never stops.** When a background task was
  never reported as finished, the panel read "Waiting for a confirmed provider update" with a
  turn timer running forever. It now says "Waiting for N background tasks", times that work,
  and stops showing a task that has reported nothing for two hours.
- **OxeQuery shows which Docker engine it uses.** Docker Desktop's engine can be empty while
  the containers run in the system engine (`/var/run/docker.sock`), which only members of the
  `docker` group may use. OxeQuery lists the local engines, says which one it is looking at,
  lets you switch, and explains a refused socket. Remote contexts are never contacted.
- **"Database worker stopped unexpectedly" says why.** The worker's error is logged and a
  masked one-line form is part of the message. A server that refuses an unencrypted
  connection (RDS, Cloud SQL, Atlas) now points at Security (TLS); an untrusted CA points at
  the CA certificate field.
- A conversation's title is the first readable text, not a raw `<artifact-content-…>` tag.
- The connection-string field shows a `mongodb://` example when MongoDB is selected.
- Builds without the speech engine (Linux) no longer offer a microphone that can only fail.

## Known limits
Unchanged from 0.17.0 and 0.17.1.
