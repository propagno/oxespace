# OXESpace 0.15.2

This patch release improves Thread status, native-session continuity and interaction clarity.

- Thread navigation now shows separate execution states: blue for ready or completed, green for running, amber when input is needed, and red on failure. Unread remains an independent marker. Claude Code and Codex use the same provider symbols as Code mode.
- A completed turn no longer leaves a command spinning when its native result was not reported. The result is marked unconfirmed, and long command details stay within the conversation width. Commands run in the conversation are distinguished from background jobs.
- Showing only the recent part of a large native session no longer blocks the composer. The notice remains visible while the conversation can continue.
- Native multiple-choice questions have selectable answers. Literal choices written in an assistant message also appear as optional draft shortcuts; selecting one does not send it automatically.

Validation: Thread UI and integration tests, Electron Playwright Thread flow, typecheck, lint and production build passed locally. The release workflow builds and verifies Windows and Linux packages before publication.
