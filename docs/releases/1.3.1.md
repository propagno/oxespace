# OXESpace 1.3.1

Fixes for conversations and Teams reported on 1.3.0. Installs of 1.3.0 on Windows update
automatically; on Linux, install the new package (the AppImage updates itself).

## Conversations

- **"View changes" on a turn shows that turn.** It opens Changes on exactly the files the turn
  changed, in the checkout where they changed (a worktree included), with the first file's changes
  open. **All changes** goes back to the branch diff. Before, it showed the branch diff of the
  project's root, so a turn in a worktree listed unrelated files.
- **File paths in a turn are relative** to their checkout, with the worktree named and the full path
  in the tooltip. Files edited in a worktree now also get Undo and Review.
- **"Needs your input" leaves room for the conversation.** It takes at most about a third of the
  view, its title and buttons stay put while the options scroll, and **Hide** gives the
  conversation back until a new request arrives.
- **Edit and Rewind are always visible** on your messages, as quiet icons with their label on hover
  or focus.
- **"Open side by side"** is disabled on the conversation already on screen, instead of opening it
  twice.
- **The cost estimate is gone from the message box.** `/spending` still shows it.
- **Diagnose a failed MCP server** from the MCP chip. OXESpace tests the saved server and says what
  is wrong: a Node.js too old for it (Ubuntu 24.04 ships Node 18), a required variable left empty,
  a password with `@` or `#` that is not encoded, a host it cannot reach, or refused credentials.

## Teams

- **A member's conversation stays reachable after it is suspended for being idle.** It keeps its
  MCP access and automatic delivery when it resumes, and a message delivered to a suspended member
  starts it again. Restarting the app still drops every member's access.
- Code panes stay bound to the member they were connected to.
- `oxespace_team_status` lists each member's session and whether it is suspended.

## Known limits

- The limits listed in [1.3.0](1.3.0.md) still apply.
