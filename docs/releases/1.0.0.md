# OXESpace 1.0.0

A new look (Mandacaru), a full OxeQuery database client, and safer command approvals in
Thread. Installs of 0.17.x update automatically; the database is backed up before the
migrations (074 to 077) run. This release also includes everything in the unreleased
0.18.0 notes (OxeQuery); see [0.18.0](0.18.0.md).

## Highlights

- **Mandacaru design.** A real light and dark mode, one set of design tokens and shared
  components across Code, Thread and OxeQuery. Dialogs and side panels close with
  Escape, keep focus inside and give it back; destructive actions say what they will
  do; scrollbars and native controls follow the theme. The whole interface is in
  English.
- **Navigation.** Team opens from the title bar, the command palette and the Tools hub,
  and says why it is unavailable. The palette and the hub share one tool list. The mode
  rail shows a badge for what needs you or failed, and a calm dot while agents work.
- **OxeQuery.** PostgreSQL and MongoDB client: SQL workbench, structure editor, schema
  tree, MongoDB workbench, organized connections, Excel export, merging import,
  containers. Details in [0.18.0](0.18.0.md).
- **Safer command approvals (Thread).** A short built-in read-only list is approved
  without a rule (switch in Rules, on by default); redirects to files, reads outside the
  project and unknown commands always ask; each prompt shows a green, orange or red
  level and prompt-injection warnings for web fetches. OXESpace only answers prompts
  the Claude or Codex CLI already raised: it can narrow what runs, never widen it.
- **Thread tools.** `/events` shows the saved events of a conversation; MCP servers can
  be imported from Claude Desktop, Cursor and Windsurf; skills accept YAML headers;
  `/instructions` shows user rules, nested rules and the paths a rule is limited to.
- **Accessibility.** File trees work with the keyboard and expose ARIA tree semantics;
  tab strips contain only tabs; the Tools menu is a real menu. Editor tabs close with
  Delete. An axe scan of 27 screens in both themes is recorded in
  `docs/validation/a11y-axe-2026-10-14.md`.

## Fixed

- **The database no longer flips its schema version at every launch.** Versions 0.15.0 to
  0.17.1 could alternate the stored version (73, 57, 73), rotate backups, and every
  second launch reset the theme chosen per workspace to `midnight`. A database that an
  old build left at version 57 loses its per-workspace theme once more, on the first
  launch of 1.0, and not again.
- Closing the only Web Preview tab and typing a new address quickly could drop the
  address.

## Upgrade notes

- Migrations 074 to 077 add columns and tables only; 077 adds per-conversation
  settings. Upgrade rehearsals run from v0.16.0 and v0.17.1.
- Shared project memory is **off** in this build (feature flag; data is untouched). It
  is not part of the 1.0 promise.

## Known limits

- `mcp-sync` writes the `env` and `headers` of MCP servers in plain text to the
  `.mcp.json` of each project it syncs. Do not commit that file if it holds secrets.
- Visual regression baselines exist for Windows only.
- Elicitation requests from Claude are not announced to the CLI.
- Ubuntu and Debian x64 are supported on Linux; other distributions are not tested.

## Not in this release

ER diagrams, schema diff, backup and restore, visual aggregation builders, database
engines other than PostgreSQL and MongoDB, GridFS, Team tasks and missions.
