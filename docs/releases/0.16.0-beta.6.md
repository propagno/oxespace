# OXESpace 0.16.0-beta.6

This beta improves Thread interaction and adds compact local diagnostics for investigating stalled tasks and process failures.

- Claude questions preserve the original question keys and support reviewing multiple answers before submission. The stdio initialization handshake and permission routing are corrected.
- Claude sessions continue observing background task events after the main turn completes. Thread activity separates tool execution, user input and background work; uncertain task outcomes remain explicit.
- Thread includes a real project terminal, clearer access confirmation and file-change grouping by scope.
- Persistent project teams share roles and inboxes across Code and Thread. Automatic delivery is opt-in, respects idle state and does not retry uncertain sends automatically.
- Delegated agents can make their first authorized MCP call while consent binding finishes. Web Preview waits for its initial tab before accepting an address.
- Settings → Diagnostics → Export report includes compact process and Thread lifecycle metadata. The new event store is capped at 1.5 MiB with seven-day retention, repetition counters and rate limiting. It excludes prompts, terminal output, arguments and environment variables. The report survives application restarts.

## Known limits

This release does not claim to fix the reported Linux GPU/syslog incident. Preserved journal evidence identifies a `claude-desktop` executable; how it was launched and its relationship to Thread remain unverified. The diagnostic storage cap does not cap Linux system logs, agent histories, the application database or crash dumps.

Authenticated Claude question/approval/background workflows, full Codex workflows, long installed sessions and a 60-minute endurance run remain pending. These limitations are carried explicitly into this beta. The publication workflow gates the final Windows and Linux builds and packaged smoke tests; fixtures and transport tests do not replace the pending authenticated checks.

Use the artifacts attached to this release. Earlier locally generated beta.6 installers predate compact diagnostics. See [release validation](https://github.com/propagno/oxespace/blob/v0.16.0-beta.6/docs/validation/release-0.16.0-beta.6.md) and [compact diagnostics validation](https://github.com/propagno/oxespace/blob/v0.16.0-beta.6/docs/validation/compact-runtime-diagnostics-2026-10-06.md).
