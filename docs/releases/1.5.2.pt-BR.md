# OXESpace 1.5.2

Uma correção de segurança no acesso das conversas. Recomendamos atualizar.

Instalações da 1.5 no Windows atualizam sozinhas; no Linux, instale o pacote novo (o AppImage se atualiza).

## Segurança

- **Acesso das conversas.** Esta versão reforça a proteção da configuração de acesso de cada conversa. Suas
  conversas, o histórico delas e suas configurações ficam como estão.

## No celular

- **Alguns comandos com barra digitados no celular não rodam mais.** Use o botão de parar do celular (**Parar o turno**) ou o app no computador.
