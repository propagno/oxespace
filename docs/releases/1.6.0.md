# OXESpace 1.6.0

A major leap in performance, visual craft, and multi-agent ergonomics across **OxeChat**, **OxeCode**, **OxeQuery**,
and the **Android** companion. Heavy terminal load stays responsive, long conversations scroll smoothly, and the
workspace brings unified controls for triaging, reviewing, and coordinating parallel agent work.

Installs of 1.5.x on Windows update automatically; on Linux, install the new package (the AppImage updates itself).

## Performance

- **Isolated terminal host by default.** Terminals now run in a dedicated background process instead of the main
  application process, keeping the interface responsive even when multiple agents stream heavy output at once.
- **Hidden-workspace parking and chunked terminal writes.** Terminals in hidden workspaces pause active rendering and
  heavy output is batched cleanly, cutting background CPU usage by roughly 64–71% and slashing command-bar (`Ctrl+K`)
  latency under load.
- **Off-thread rendering and virtualized timelines.** Markdown, syntax highlighting, Mermaid diagrams, LaTeX formulas,
  and diffs are parsed in a background Web Worker, and long conversations virtualize their timeline so scrolling and
  switching threads stay fast.
- **Faster startup and lighter idle footprint.** Opening OXESpace uses a single database open, asynchronous shell PATH
  lookup, SQL-level change summaries, lazy-loaded panels and code chunks, and paused pollers while hidden.

## OxeChat & Interface

- **Refreshed Mandacaru design system.** Unified controls across conversations, panels, dialogs, and settings, with
  refined typography, spacing, and compact or comfortable density modes. Exposed header panels stay clear even in
  narrow `960×720` empty states, and the Web Preview browser bar adapts cleanly into a single row on narrow widths.
- **Sidebar triage and nested conversations.** Filter conversations by state (**All**, **Needs you**, **Working**),
  group them by project, and follow parallel or delegated child conversations nested directly under their parent.
- **Conversation origin and concurrent-writer warning.** Choose where a new conversation starts (the current workspace
  or an isolated worktree) and see a clear warning when another active conversation is already writing to the same
  working tree.
- **Workspace access ceiling.** Set a maximum access level per workspace so no conversation inside it can exceed the
  permissions you allow.
- **Review scopes and cross-agent review.** Review changes scoped to staged files or the last turn, leave inline diff
  comments, and ask another agent to review the latest turn's changes.
- **Web Preview captures and subagent cards.** Capture elements from the Web Preview directly as conversation
  artifacts, and inspect delegated subagent outputs in dedicated result cards.
- **Richer day-to-day ergonomics.** Progressive session listing when resuming conversations, Mermaid zoom and export,
  improved MCP server management (edit, toggle, and updated templates), and a working-set bar for active files.

## OxeCode, OxeQuery & Android

- **OxeCode state filters and handoff trail.** Filter the OxeCode sidebar by **All**, **Needs you**, or **Working**,
  follow workspace handoffs with worktree attachments and inbound notice banners, and switch grid layouts without
  losing running sessions.
- **OxeQuery polish.** Unified sidebar and query editor layout, faster result grids, context menus, and clearer error
  messages.
- **Android companion and emulator panel.** Hardened emulator lifecycle and ownership controls (with a lightweight
  emulator memory option), optional desktop VPN adapter access (off by default, audited) wired to the mobile app,
  Settings accessible directly from the phone's home screen, and a clearer camera permission prompt during pairing.
- **Reliability.** Stricter end-to-end type coverage, safer renderer crash recovery, clean terminal shutdown on quit,
  and guaranteed state flushing before exit.

## Verify the Android APK

Before installing `oxespace-android-v1.6.0.apk`, check that it's the published file and that the project's key signed
it:

1. `sha256sum -c oxespace-android-v1.6.0.apk.sha256` (both files are in this release's assets).
   On Windows: `Get-FileHash oxespace-android-v1.6.0.apk` in PowerShell, and compare it with the value in the `.sha256`
   file.
2. `apksigner verify --print-certs oxespace-android-v1.6.0.apk` (Android SDK build-tools). The line
   `Signer #1 certificate SHA-256 digest:` must read `cc65d90afa2fde6518adad92d40769496a043b901f603eff0562e056cd4336e4`.

The signing certificate's SHA-256 fingerprint is:

`CC:65:D9:0A:FA:2F:DE:65:18:AD:AD:92:D4:07:69:49:6A:04:3B:90:1F:60:3E:FF:05:62:E0:56:CD:43:36:E4`

It's the same key as 1.5.x, so the app updates in place. The full steps are in
[Verifying an APK before installing it](https://github.com/propagno/oxespace/blob/main/mobile/android/RELEASING.md#verifying-an-apk-before-installing-it).
