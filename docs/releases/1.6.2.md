# OXESpace 1.6.2

A focused stability and polish update following 1.6.1, making **Antigravity** reliable in both **OxeChat** and the
Windows ConPTY terminal, bringing official SVG marks for every AI provider, fixing **Usage & rate limits** across
Codex, Claude, and Antigravity, preserving **WebPreview** access across chat switches, and right-aligning user prompts
in **OxeChat**.

Installs of 1.6.1 on Windows update automatically; on Linux, install the new package (the AppImage updates itself).

## Antigravity in OxeChat & Terminal

- **Reliable Antigravity connection and verification in OxeChat.** Fixed `Connect` and `Verify` failures when workspaces
  were hidden or closed, added Windows `%LOCALAPPDATA%\agy\bin` PATH discovery and JSON-RPC 2.0 normalization, raised
  the native ACP frame limit to 32 MiB, auto-opened the OAuth sign-in URL cleanly, and replaced generic failures with
  actionable error messages.
- **Clean inline TUI rendering on Windows ConPTY.** Configured `@xterm/xterm` 6 with Windows ConPTY build detection,
  VT/DEC-2026-safe scrollback trimming with a 1 MiB ring buffer, accurate initial geometry, clean redraw nudging on
  reattach, and updated xterm 6 viewport styling so Antigravity and other inline TUIs render cleanly in OxeCode panes.

## OxeChat Experience & WebPreview

- **Right-aligned user message bubbles.** Your own messages in OxeChat now sit flush right inside the conversation column
  with clear separation from left-aligned agent responses, hover actions positioned below the bubble without obscuring
  short prompts, and full-width comfort while editing.
- **Preserved WebPreview access and settings across chats.** Switching between conversations in OxeChat and returning to
  a thread with the embedded Browser open now preserves its **Agent access**, **External preview**, **Auto-verify**,
  **Zoom**, and **Device emulation** settings per conversation while maintaining strict main-process `T43` revocation
  and `A49` grant boundaries.
- **Polished New Conversation screen.** Removed the duplicate inner focus ring and native textarea resize handle, unified
  the composer border and pill controls, added localized `Enter` / `Shift+Enter` keyboard hints, and elevated starter
  cards.

## Usage, Rate Limits & Provider Identity

- **Accurate Usage & rate limits across Codex, Claude, and Antigravity.**
  - **Codex:** expired local-session windows no longer hijack the unified status bar percentage or keep it permanently in
    warning orange, show honest local-session copy instead of network-error text, preserve plan badges, and display full
    dates for past-day readings.
  - **Claude:** sends the installed `claude --version` in the `User-Agent`, checks expired OAuth tokens locally before
    making requests, throttles inactive background polling to avoid `429` bursts, and shows friendly retry messages in
    place of raw HTTP codes.
  - **Antigravity & Modal UX:** replaces `"Reset time unknown"` with **Quota available** at `0%` used, synchronizes the
    modal with the status bar store, widens the modal card layout to prevent awkward wrapping, and notes when Gemini's
    weekly quota is only reported via `agy /usage`.
- **Official AI provider symbols.** Replaced generic placeholder icons with official SVG marks for **Antigravity**,
  **Claude**, **Codex**, **Cursor**, **Copilot**, and **Grok** across sidebars, headers, status bar popovers, and the
  Usage & rate limits dialog.
- **Cleaner terminal auto-titles.** Stripped temporary `oxe-paste-*.png` image file paths from automatically derived
  terminal pane titles, `lastIntent`, and sidebar session summaries.

## Release & CI Infrastructure

- **Lean 8-workflow GitHub Actions standard.** Consolidated 30 legacy and ghost workflows into 8 canonical workflows with
  shared composite actions, faster parallel PR checks, and a unified Desktop + Android release pipeline.

## Verify the Android APK

Before installing `oxespace-android-v1.6.2.apk`, check that it's the published file and that the project's key signed
it:

1. `sha256sum -c oxespace-android-v1.6.2.apk.sha256` (both files are in this release's assets).
   On Windows: `Get-FileHash oxespace-android-v1.6.2.apk` in PowerShell, and compare it with the value in the `.sha256`
   file.
2. `apksigner verify --print-certs oxespace-android-v1.6.2.apk` (Android SDK build-tools). The line
   `Signer #1 certificate SHA-256 digest:` must read `cc65d90afa2fde6518adad92d40769496a043b901f603eff0562e056cd4336e4`.

The signing certificate's SHA-256 fingerprint is:

`CC:65:D9:0A:FA:2F:DE:65:18:AD:AD:92:D4:07:69:49:6A:04:3B:90:1F:60:3E:FF:05:62:E0:56:CD:43:36:E4`

It's the same key as 1.5.x, 1.6.0, and 1.6.1, so the app updates in place. The full steps are in
[Verifying an APK before installing it](https://github.com/propagno/oxespace/blob/main/mobile/android/RELEASING.md#verifying-an-apk-before-installing-it).
