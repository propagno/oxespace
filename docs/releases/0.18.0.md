# OXESpace 0.18.0

OxeQuery grows into a full database client for PostgreSQL and MongoDB: a SQL editor
you can work in all day, a structure editor, a real MongoDB workbench, organized
connections, Excel export and a merging import. Installs of 0.17.x update
automatically; the database is backed up before migrations 075 and 076 run.

## Highlights

- **SQL workbench.** Run the statement under the cursor (`Ctrl+Enter`) or everything
  (`Ctrl+Shift+Enter`, one result tab per statement); `:name` and `$1` parameters asked
  for before running; manual transactions with a visible "transaction open" state; tabs
  that come back when you reopen the connection; a formatter and snippets; a grid for
  100 000 rows (keyboard, block selection, column resize and hide, server-side sort,
  cell viewer, copy as CSV, TSV, JSON, Markdown or INSERT); a filter bar for tables.
- **Table structure editor.** Create a table or change columns, keys, foreign keys and
  indexes with the exact SQL shown first and applied in one transaction. Rename,
  duplicate, truncate, drop, VACUUM, ANALYZE and REINDEX, with what depends on a table
  and who may use it. Destructive changes and anything on production need a tick.
- **Schema tree for big databases.** Views, materialized views, functions, sequences,
  types, triggers and extensions; one search across every schema; pinned tables; arrow
  keys. A **Server** panel lists databases (create, drop) and roles.
- **MongoDB workbench.** Fields checked as JSON before they are sent, a tree view,
  clone, explain in words, cancel; **change many** that counts first and runs only for
  the number you confirmed; create, rename and drop collections; statistics and
  validation rules; library and history; aggregate paging.
- **Connections.** Favorites, recent, groups, colors, search, duplicate, export and
  import (without passwords), **connect without saving**, the **SSH agent**, keep-alive,
  a *Reconnect* bar when a connection drops.
- **Data.** Export to **Excel (.xlsx)**; import with a chosen delimiter, encoding and
  header row, and **skip or update** rows whose key exists.
- **Containers.** Compose projects (up, start, stop, restart, logs, down), Podman image
  names that work without registry setup, and a live test suite that runs on Docker and
  Podman.
- **Agents.** *Ask agent* sends a prompt (statement, error or plan, table and column
  names, never rows) to your agent terminal. OxeQuery settings cap agent access by kind
  of environment; containers are visible to agents only through a connection with agent
  access on; each connection can name columns agents must not see.

## Safer

- MongoDB edits no longer retype numbers (Int64, Double, Decimal128) and writes only
  match a document that still equals the one you opened.
- Secrets are refused when Linux can only offer plain-text storage (override with
  `OXESPACE_ALLOW_WEAK_SECRETS=1`); history and audit no longer keep literals such as
  passwords in `ALTER ROLE`.
- Listings say "showing N of M" instead of cutting silently; results stop at 100 000
  rows or 32 MB and say which; removing a volume and deleting a connection are
  confirmed in the main process.
- Structure changes are sent as data: the app builds the DDL, quotes every name and
  accepts only a single validated expression for a default or a check.

## Fixed

- Typing in the SQL editor under load could lose or reorder characters.
- Browsing another table left a stale "Definition" panel on the page.
- An export that failed to start (a file that already exists) could leave the connection
  waiting on an open cursor.
- The results column now scrolls in a short window instead of squeezing the grid.

## Upgrade notes

- Migration 075 adds columns to the connections table (group, favorite, color, masked
  names, keep-alive, SSH agent); 076 adds a preferences table. No rows are rewritten.
- The bundle budget of the OxeQuery view chunk is 320 kB (about 250 kB used).

## Not in this release

ER diagrams, schema diff, backup and restore, visual aggregation builders, other
engines, GridFS.
