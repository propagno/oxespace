# OXESpace 1.5.1

Emergency fixes for 1.5.0: screens that opened broken, terminal text flickering with Claude Code, and the terminal
on the phone, which now fits the phone's screen.

Installs of 1.5.0 on Windows update automatically; on Linux, install the new package (the AppImage updates itself).

## Terminal

- **Text no longer flickers with Claude Code.** Claude Code redraws its screen many times a second and asks the
  terminal to show each frame only once it is complete (synchronized output). OXESpace's terminal now honors that
  request (xterm 6). The terminal's scrollbar is now drawn by the terminal itself.
- **On the phone, the terminal fits the screen.** While a terminal is open on the phone, the computer draws the CLI
  at the phone's width instead of showing the part of the computer's screen that fits. When you leave the terminal
  on the phone, the pane goes back to the computer's size. Meanwhile the pane on the computer says it is sized for
  the phone and offers **Take back**.

## OxeChat

- **The conversation opens and scrolls again.** Finished background commands covered the whole conversation. Each is
  now one line; only the latest two stay in view (**Show earlier** brings the rest), and **Show output** opens the
  output.
- **Terminal and Pull request tabs** use the full height (they stopped halfway before).
- **Terminal tab:** click a terminal to open it in OxeCode, in its workspace.
- **Pull request tab:** cards, a colour for each check's state, and the actions next to the title. **Address review
  comments** writes the request into the conversation again.
- **Android panel** in a conversation: the no-device notice is centred.
- **Approval queue:** covers the window to the bottom, with no sidebar footer showing underneath.

## Upgrading from 1.4

- **The "OXESpace 1.5 removed some features" notice** is a card in the window's corner, in the theme's colours. It
  used to squeeze under the sidebar and push the window up.
- **What changed in 1.5** shows a table (what left · what to use now) and where your data was saved.

## Not measured yet

- The phone-sized terminal was verified by tests, not on a device.
