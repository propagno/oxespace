# OXESpace 0.14.0-beta.1

This prerelease introduces the Thread workbench alongside Code mode. Threads now have project-aware navigation, persistent conversation history, formatted messages, attachments, model and effort controls, slash commands, file review, and access to native Codex and Claude sessions where the provider is installed and authenticated.

Delegation can create independent Git worktrees using a chosen existing branch, an exact new branch name, or a locally generated name. Its handoff can include explicitly selected Thread conversations and AI Memory context. Saved delegation tasks and linked sessions are designed to be discoverable and resumable after restarting OXESpace.

The release also updates Settings, navigation, session details, error presentation, and Thread/Code visual consistency. It includes database migrations and automated coverage for Thread persistence, provider behavior, delegation, worktrees, and knowledge transfer.

## Beta limitations

- Claude subscription sign-in and delegated session resume still require validation with a live, authenticated Claude installation on the target machine.
- The internal OXESpace quality controller reported `CONTRACT_CONSUMERS_UNCHANGED` during development; its heuristic result has not been reconciled with the passing typecheck, build, and automated tests. This beta should receive a focused end-to-end review before a stable release.
- Native provider features depend on the installed CLI version, account permissions, and provider availability.
