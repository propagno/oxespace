The menu groups management of the current conversation separately from search/resume and transfer. “Find or resume session…” names the destination explicitly; “Open conversation” was ambiguous while already inside an open conversation. Session-row actions appear on hover or keyboard focus, and assistant Copy response no longer occupies its own line. The interface is an adaptation of these interaction patterns, not a feature-for-feature clone. OXESpace still lacks the standalone Agents window and some provider-specific inline tool controls.

The visual default is the Workbench (`midnight`) palette shown in the user-provided Code reference. Schema migration 058 adopts Workbench once for pre-existing workspaces; subsequent user theme changes remain saved. New terminals use Cascadia Mono first with Linux fallbacks, 16px, 1.4 line height and zero letter spacing. The v7 terminal preference migration repairs the accidental persisted 32px ceiling caused by window-wide zoom shortcuts. Settings exposes reset controls when the stored font size differs from the application default.

The Thread sidebar's primary action is Add project; the plus button on a project opens its new-conversation dialog. The conversation uses a wider 1100px reading canvas and a persisted text-size control independent of terminal font settings. Agent selection in New thread uses visible options. Project changes opens tracked Markdown files in a wide reading dialog, while leaving their diff in the review panel.
